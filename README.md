# Hyprland Dotfiles

My custom Hyprland ricing configuration files.

## Structure
- `.config/hypr/` - Hyprland window manager configuration & custom scripts
- `.config/waybar/` - Status bar modules & styling
- `.config/swaync/` - Notification center configuration & CSS
- `.config/rofi/` - Application launcher & menus
- `.config/wofi/` - Alternative Wayland application launcher
- `.config/kitty/` - Terminal emulator configuration
- `.config/cava/` - Audio visualizer settings & shaders
- `.config/fastfetch/` - Fastfetch system info styling
- `.config/neofetch/` - Neofetch styling
- `.config/nwg-look/` - GTK theme settings manager
- `.config/xsettingsd/` - XWayland settings daemon configuration
- `.config/gtk-3.0/` & `.config/gtk-4.0/` - GTK themes & window decoration styles
- `.zshrc` - Zsh configuration

## Installation / Linking
To symlink these configurations into `~/.config` and `~`:
```bash
./setup.sh
```
